\section*{Resumen}

Este informe documenta \textbf{SalesHealth}, entrega final de la asignatura
Gestión de Datos (UAX, curso 2025/26). Sobre un dataset relacional sintético
del sector salud y bienestar ($5\,750$ clientes, $20\,000$ tickets, $42\,555$
líneas, $2\,330$ devoluciones, ventana 2020-01--2026-01) se construye un
\emph{Data Warehouse} en estrella sobre PostgreSQL, se calcula el CLTV por
cliente y se segmenta la base mediante PCA y KMeans. El ETL queda
automatizado por seis notebooks numerados, con cobertura de \texttt{pytest}
sobre la integridad referencial del DWH y la consistencia de la fórmula
de CLTV.
