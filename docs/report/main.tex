\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}

Este informe documenta el proyecto \textbf{SalesHealth}, entrega final de la
asignatura Gestión de Datos del curso 2025/26 en la Universidad Alfonso X El
Sabio. Sobre un dataset relacional sintético del sector salud y bienestar
($5\,750$ clientes, $20\,000$ tickets de venta, $42\,555$ líneas, $2\,330$
devoluciones, ventana 2020-01--2026-01) se construye un \emph{Data Warehouse}
con esquema en estrella sobre PostgreSQL, se calcula el \emph{Customer
Lifetime Value} (CLTV) por cliente según la fórmula del enunciado
$\mathrm{CLTV} = \text{Ingresos}_t \times \text{Margen}_t \times
\text{Frecuencia}_t \times R_t$, y se segmenta la base mediante PCA y KMeans
sobre ocho métricas derivadas. La cadena ETL queda automatizada por seis
notebooks numerados y por SQL idempotente; los resultados se consumen desde
un dashboard estático HTML+Plotly servido por Flask. El proyecto incluye una
batería de pruebas \texttt{pytest} para la integridad referencial del DWH y
para la consistencia de la fórmula de CLTV.
